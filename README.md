# 등불 심연

기름이 닳기 전에 심연 8층의 불씨를 찾는 턴제 로그라이크. 키보드만으로 끝까지 할 수 있다.

👉 https://yh-yeop.github.io/LanternDeep/

## 하는 법

- 걸을수록, 쉴수록 등불 기름이 닳고 기름이 줄면 보이는 범위도 줄어든다. 0이 되면 어둠이 체력을 갉아먹는다.
- 적은 어둠 속에서도 내 불빛을 보고 다가온다.
- 계단(`>`)으로 내려가 8층의 **심연의 불씨**(`✦`)를 주우면 승리. 불씨는 심연지기가 지킨다.
- 레벨이 오르면 특성 3개 중 하나를 고른다 (체력, 공격, 방어, 시야, 기름 절약, 흡혈, 치명타, 회피).
- 매 턴 자동 저장. 탭을 닫아도 처음 화면에서 이어하기.

| 동작 | 키 |
|---|---|
| 이동 · 공격 | 방향키 · WASD · hjkl |
| 대각선 | QEZC · yubn · 숫자패드 7 9 1 3 |
| 대기 | Space · `.` · 숫자패드 5 |
| 쉬기 (다 나을 때까지, 적이 보이면 멈춤) | R |
| 붕대 · 기름병 · 섬광탄 | 1 · 2 · 3 |
| 내려가기 | `>` · Enter |
| 도움말 | `?` |

키는 물리 위치(`KeyboardEvent.code`)로 읽어서 한글 입력 상태에서도 된다. 폰에서는 화면 패드나 지도 탭으로 움직인다.

## 구성

빌드 없음. 의존성 없음.

| 파일 | |
|---|---|
| `index.html` | 화면 틀 · 창(시작 · 레벨 업 · 도움말 · 끝) |
| `style.css` | 스타일 |
| `game.js` | 던전 생성 · 시야 · 턴 · 적 AI · 저장 · 그리기 · 입력 |
| `sw.js` | 오프라인 캐시. 파일을 바꾸면 `VERSION`을 올린다 |

- 저장 `localStorage["lantern:save"]`, 기록 `localStorage["lantern:best"]`
- 콘솔에서 `__lantern`으로 상태를 볼 수 있다 (자동 테스트용).
