# 등불 심연

기름이 곧 탄약이자 불빛인 실시간 던전 슈팅 로그라이트. 키보드만으로 끝까지 할 수 있다.

👉 https://yh-yeop.github.io/LanternDeep/

## 하는 법

- **기름 = 탄약 + 불빛.** 무기를 쏠 때 기름이 닳고(무기마다 소모량이 다름), 줄어들수록 불빛 반경이 작아진다. 자동 조준도 불빛 근처까지만 된다. 기름이 모자라면 등불로 후려친다(무료 근접).
- 적을 쓰러뜨리거나 방을 정리하면 기름이 나온다. 어둠 속의 적은 눈빛만 보인다.
- 방에 들어가면 문이 잠기고 웨이브를 모두 쓰러뜨려야 열린다. 보물방 상자에서 새 무기, 출구방 계단에서 다음 층.
- 층을 내려갈 때 특성 3개 중 하나를 고른다. 5층 출구의 심연지기를 쓰러뜨리고 불씨를 주우면 승리.
- 층을 시작할 때마다 저장. 처음 화면에서 그 층 시작부터 이어하기.

| 동작 | 키 |
|---|---|
| 이동 | WASD · 방향키 |
| 공격 (누르고 있으면 연사, 자동 조준) | J · Space |
| 구르기 (짧은 무적) | K · Shift |
| 무기 교체 | Q (1 · 2로 바로 고르기) |
| 줍기 · 상자 열기 · 내려가기 | E · Enter |
| 일시정지 · 도움말 | Esc · P · `?` |

키는 물리 위치(`KeyboardEvent.code`)로 읽어서 한글 입력 상태에서도 된다. 폰에서는 왼쪽 스틱과 버튼으로 한다.

### 무기

| 무기 | 기름 | 특징 |
|---|---|---|
| 불씨 권총 | 0 | 기본 |
| 광부 곡괭이 | 0 | 근접, 적 탄을 쳐낸다 |
| 연발 부싯돌 | 1 | 빠른 연사 |
| 반딧불 주머니 | 2 | 유도 탄 3발 |
| 산탄 등불 | 3 | 짧은 산탄 6발 |
| 빛창 | 4 | 관통 |
| 기름 투척기 | 6 | 폭발 |

## 구성

빌드 없음. 의존성 없음.

| 파일 | |
|---|---|
| `index.html` | 화면 틀 · 창(시작 · 특성 · 일시정지 · 도움말 · 끝) |
| `style.css` | 스타일 |
| `game.js` | 층 생성 · 충돌 · 무기 · 적 AI · 방 전투 · 어둠 · 미니맵 · 저장 · 입력 |
| `sw.js` | 오프라인 캐시. 파일을 바꾸면 `VERSION`을 올린다 |
| `portfolio.json` | 소개 사이트(yh-yeop.github.io) 등록 정보 |

- 저장 `localStorage["lantern2:save"]`(층 시작 시점), 기록 `localStorage["lantern:best"]`
- 콘솔의 `__lantern`으로 상태를 보고 `step(dt)`로 한 프레임씩 돌릴 수 있다 (자동 테스트용).
